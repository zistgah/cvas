## How to contribute

1. Open an issue or a pull request on the staging repository.
2. You receive a ticket. The ticket is an honor. Identity is not verified.
3. Submit a component. The pipeline checks it.
4. If the pipeline passes, the staging repository auto-accepts and indexes the work.
5. The main repository does not auto-accept. A human promotes.

## Plagiarism

The index is checked. A high overlap holds. It does not accuse. A human decides.

## What you do not need

You do not need to know the kernel. You do not need a local install beyond a container. You do not need to be known.
