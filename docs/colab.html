How the notebook works

  1. Open the notebook from the repository in Google Colab.
  2. Upload the CVAS harness ZIP for this iteration.
  3. Upload one component ZIP containing its manifest, implementation and tests.
  4. The notebook checks archive paths and limits before extraction.
  5. The JavaScript-first verifier runs in the temporary Colab runtime. Python is used for Colab upload/download and safe archive handling; Python component support remains available.
  6. Inspect the check-by-check outcome and download the JSON evidence report.

Implementation policy

CVAS is web-first and JavaScript-first. The primary verifier is Node.js. Python remains supported for Python components and scientific workloads. The notebook uses Python only for Colab-specific upload/download, archive handling and orchestration.

What you need

  • A Google account with access to Colab.
  • A browser and network connection.
  • The published CVAS harness ZIP and a component ZIP.
  • No desktop IDE or local development environment.
Security warning: the notebook executes contributor-supplied code. Do not mount Google Drive, upload private files, enter credentials or use a runtime with secrets. Colab is an ephemeral convenience environment, not an isolated hostile-code sandbox. For untrusted hostile submissions, use a controlled runner with network disabled, resource limits and disposable isolation.
