NORMATIVE IMPLEMENTATION POLICY

Web-first.
JavaScript-first.

Use the browser platform and JavaScript wherever they can do the work. Retain Python where its ecosystem materially helps.

Technology priority

HTML, CSS and browser JavaScript

Static site, contributor experience, documentation, client-side validation and browser workflows. No backend is required for GitHub Pages.

Node.js

Primary verifier, component runtime, CI automation, manifest processing and command-line integration.

Python retained

Python components remain supported. Use Python for scientific libraries and workloads where it is materially advantageous, and for Colab-specific upload/download and archive orchestration.

Browser-only contributor path

  1. Open the CVAS repository in Google Colab.
  2. Upload the harness archive and component archive through the notebook UI.
  3. Colab validates and extracts the archives.
  4. Node.js runs the primary CVAS verifier and JavaScript component tests.
  5. Python components are run through the retained Python adapter.
  6. Download the verification report and submit the contribution through GitHub's browser interface.
AI-agent requirement: read CONTRACT.md before changing CVAS. Preserve JavaScript-first implementation, Python support, browser-only contribution, 110% verification, HOLD/INCOMPLETE semantics, evidence provenance, replaceability, risk routing and copyright/licence notices.

What this does not mean

Python is not deprecated. Node.js is not a substitute for scientific Python libraries when those libraries are the right tool. “JavaScript-first” means avoid introducing Python for tasks already well served by browser APIs or Node.js.
